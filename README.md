## 📐 Mathematics Behind Computing

I am particularly interested in seeing how discrete mathematics becomes engineering.

| Mathematical idea       | Computing interpretation                               |
| ----------------------- | ------------------------------------------------------ |
| **Propositional Logic** | Conditions, policies, authorization, digital logic     |
| **Set Theory**          | Data models, membership, permissions and relationships |
| **Combinatorics**       | State spaces, configurations and possibilities         |
| **Graph Theory**        | Networks, routing, dependencies and system topology    |
| **Probability**         | Reliability, failures, uncertainty and performance     |

For example:

```text
Logic       → What is true?
Sets        → What belongs where?
Combinatorics → How many possibilities?
Graphs      → How are things connected?
```

These mathematical abstractions become particularly powerful when reasoning about distributed systems.
